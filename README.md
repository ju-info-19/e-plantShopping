# 🌿 Paradise Nursery - E-Plant Shopping

## Description
Paradise Nursery est une application e-commerce moderne permettant aux utilisateurs de parcourir, sélectionner et acheter des plantes d'intérieur.

## Fonctionnalités
- 🌱 Catalogue de plantes par catégories (Green Plants, Flowering Plants, Succulents)
- 🛒 Panier d'achat interactif
- ➕ Ajout, suppression, modification des quantités
- 💰 Calcul automatique du total
- 📱 Interface responsive

## Technologies
- React 18
- Redux Toolkit
- CSS3

## Installation
```bash
git clone https://github.com/ju-info-19/e-plantShopping.git
cd e-plantShopping
npm install
npm start
